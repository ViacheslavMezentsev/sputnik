# Источники событий

Журнал (`events.jsonl`) — строки JSON: `t0`, `t1` (UTC), `kind`, `source`, `subject` и поля источника.
Ниже — где искать события в проекте, что из них берётся и насколько это точно.

| Источник | Где найти | Что берётся | Точность |
| --- | --- | --- | --- |
| Коммиты | `git log A..B` | время автора, тема (тип Conventional Commits), ветка — по слиянию, которое принесло коммит | время — факт; длительность работы — оценка (окно до коммита) |
| Слияния | слияния в истории (`Merge branch 'x' into 'y'`, `Merge pull request #n from …`) | ветка, куда слита; число конвейеров MR и слияния | факт события; длительность конвейера — оценка |
| Теги | `git tag --points-at` | время тега, конвейер выпуска | то же |
| Прогоны stm32-gdbtest | `build/<пресет>/hwtest/runs/<run>/result.json` | сценарий, статус, начало, длительность, локальный или удалённый сервер | факт |
| Журнал моста стенда | `results/<id>/summary.json` (`started_utc`, `seconds`, `status`, `git.branch`, `steps`) | задание: что запущено, сколько шло, чем кончилось | факт; один запуск человеком на задание |
| Локальный CI | каталоги с меткой времени (`local-ci-YYYYMMDD-HHMMSS-…`), отчёты `summary.json` | момент прогона | время — факт, длительность — по отчёту или правилу |
| CI сервера | API GitLab/GitHub, если доступно; иначе — слияния и теги | конвейеры и их длительность | с API — факт, без — оценка |
| Записи испытаний | rosbag/mcap (время в имени, длительность в индексе), сессии анализатора, архивы лаборатории | начало и конец записи | ±минуты: часы записи и ПК различаются |
| Пакеты сборок | архивы `*_package.zip` для испытаний | момент передачи сборки | время файла |
| Документы | ревизии ТЗ, плана испытаний, памятки (коммиты `docs(spec)`, `docs(todo)`) | моменты решений | факт |
| Ручные события | со слов владельца: замер, нажатия, смена платы, доработка платы | `manual.csv` | оценка |

Порядок поиска:

1. `git log --format='%aI %s' A..B`, слияния `--merges`, теги — границы и рабочие ветки.
2. Каталоги сборки: `**/hwtest/runs/*/result.json`, `**/local-ci-*`, `**/*_package.zip`.
3. Журналы стендов и мостов рядом с проектом (`results/*/summary.json`) — с фильтром по полю `repo`.
4. Записи испытаний: `*.bag`, `*.mcap`, `*.sr`, `*.sal`, архивы с ними — время начала по имени, конец — по
   длительности; часовой пояс имени уточнить.
5. Памятка и CHANGELOG — что было сделано и в каком порядке, если журналов нет (ранние этапы).

Окно событий кроме git — от времени предыдущего тега до последнего коммита плюс 14 дней (`--until`).
Часовой пояс календаря задаётся `--tz` при выводе; в журнале всё в UTC.
